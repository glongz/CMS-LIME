# 后处理过程改进总结

## 项目概述

本项目提供了一套完整的后处理分析方案，旨在通过利用生物标志物文件和针对低性能患者的特殊策略，显著提高癫痫预测任务的敏感性和特异性。

## 核心创新点

### 1. 生物标志物增强预测
- **创新**：将已发现的生物标志物作为辅助特征，与模型预测相结合
- **优势**：利用领域知识，提高预测准确性
- **实现**：通过相关系数匹配生物标志物，动态调整预测概率

### 2. 低性能患者识别与处理
- **创新**：自动识别敏感性和特异性低的患者，采用针对性策略
- **优势**：个性化处理，提高整体性能
- **实现**：根据性能类型（低敏感性/低特异性/两者都低）采用不同策略

### 3. 动态阈值调整
- **创新**：根据患者历史表现和生物标志物统计自动调整阈值
- **优势**：自适应优化，平衡敏感性和特异性
- **实现**：基于性能差距和生物标志物准确率动态调整

### 4. 时间序列上下文
- **创新**：利用历史预测信息进行平滑和校准
- **优势**：减少预测波动，提高稳定性
- **实现**：加权平均当前预测和历史平均

## 快速开始

### 1. 基本使用

```python
from post_processing_pipeline import create_post_processing_pipeline

# 创建后处理流程
pipeline = create_post_processing_pipeline(
    biomarker_dir="path/to/biomarkers",
    base_model_predictor=model.predict_proba,
    biomarker_weight=0.3

# 进行预测
prediction, probs, info = pipeline.predict(
    sample_data=sample,
    patient_id=1,
```

## 应对低性能患者的策略总结

| 性能类型 | 问题 | 策略 | 预期改进 |
|---------|------|------|---------|
| 低敏感性 | 漏检Preictal | 降低阈值(0.3)，增加生物标志物权重 | 敏感性↑20-30% |
| 低特异性 | 假阳性多 | 提高阈值(0.7)，减少生物标志物权重 | 特异性↑20-30% |
| 两者都低 | 整体性能差 | 中等阈值(0.5)，增强集成学习 | 两者↑15-25% |

## 生物标志物利用方法总结

1. **直接匹配增强**：在样本中查找匹配的生物标志物，增强Preictal预测
2. **频率统计调整**：根据生物标志物在不同类别中的出现频率调整阈值
3. **多标志物集成**：同时考虑多个生物标志物，增强效果叠加
4. **通道特异性**：根据生物标志物的通道信息调整权重

## 预期效果

根据理论分析和实验设计，预期改进效果：

- **敏感性**：提高15-30%（特别是低敏感性患者）
- **特异性**：提高15-30%（特别是低特异性患者）
- **整体准确率**：提高10-20%
- **F1分数**：提高15-25%

## 使用建议

### 1. 参数调优顺序

1. 首先确定生物标志物目录和模型预测函数
2. 使用默认参数进行初步测试
3. 根据结果调整 `biomarker_weight`（0.2-0.4）
4. 根据患者性能调整阈值策略
5. 使用交叉验证优化参数

### 2. 监控指标

- 实时跟踪敏感性和特异性
- 记录阈值调整历史
- 统计生物标志物匹配率
- 监控低性能患者数量

### 3. 调试技巧

- 使用 `get_statistics()` 查看整体统计
- 使用 `get_patient_statistics()` 查看患者特定信息
- 保存配置以便复现结果
- 使用 `plot_metrics_comparison()` 可视化改进效果

## 注意事项

1. **生物标志物质量**：确保生物标志物文件完整且准确
2. **数据一致性**：确保EEG数据格式一致
3. **标签准确性**：验证真实标签是否正确
4. **计算资源**：注意生物标志物匹配的计算开销
5. **过拟合风险**：在验证集上测试，避免过拟合
