## 概述

本后处理改进方案旨在通过以下方式提高癫痫预测任务的敏感性和特异性：

1. **生物标志物增强**：利用已发现的生物标志物作为辅助特征
2. **低性能患者特殊处理**：针对敏感性和特异性特别低的患者采用专门策略
3. **动态阈值调整**：根据患者历史表现和生物标志物出现情况动态调整预测阈值
4. **时间序列上下文**：利用历史预测信息进行平滑和校准

## 核心策略

### 1. 生物标志物增强预测

**原理**：
- 生物标志物是在Preictal阶段出现的特定EEG模式
- 如果当前样本中检测到生物标志物，增加预测为Preictal的概率
- 通过相关系数计算生物标志物与样本的匹配度

**实现**：
- `BiomarkerMatcher`：匹配样本中的生物标志物
- `BiomarkerEnhancedPredictor`：结合模型预测和生物标志物信息

**参数调整**：
- `biomarker_weight`：控制生物标志物的影响权重（建议0.2-0.4）
- `min_biomarker_confidence`：生物标志物最小置信度阈值（建议0.5-0.7）

### 2. 低性能患者识别与处理

**识别标准**：
- 敏感性 < 0.5 或 特异性 < 0.5
- 可以自定义阈值

**处理策略**：

#### 敏感性低（特异性正常）
- **问题**：漏检Preictal样本
- **策略**：
  - 降低预测阈值（从0.5降到0.3）
  - 增加生物标志物权重（1.5倍）
  - 增强集成学习权重

#### 特异性低（敏感性正常）
- **问题**：假阳性过多
- **策略**：
  - 提高预测阈值（从0.5升到0.7）
  - 减少生物标志物权重（0.8倍）
  - 采用更保守的预测

#### 两者都低
- **问题**：整体性能差
- **策略**：
  - 使用中等阈值（0.5）
  - 显著增加集成学习权重（1.5倍）
  - 扩大时间序列上下文窗口（10个样本）

### 3. 动态阈值调整

**原理**：
- 根据患者历史表现自动调整预测阈值
- 如果敏感性低，降低阈值；如果特异性低，提高阈值
- 考虑生物标志物出现频率和准确率

**调整规则**：
```
如果 敏感性 < 目标值(0.8):
    阈值 -= 调整步长(0.05) * 2

如果 特异性 < 目标值(0.8):
    阈值 += 调整步长(0.05) * 2

如果 生物标志物预测Preictal准确率 > 0.7:
    阈值 -= 0.15  # 生物标志物可靠，降低阈值
```

### 4. 时间序列上下文

**原理**：
- 利用历史预测信息进行平滑
- 减少预测的波动性
- 提高预测的稳定性

**实现**：
- 维护每个患者最近100个预测的历史记录
- 使用加权平均结合当前预测和历史平均
- 权重：当前预测0.6，历史平均0.4

## 应对低性能患者的策略

### 策略1：降低阈值（敏感性低）

**适用情况**：敏感性 < 0.5，特异性正常

**操作**：
- 将预测阈值从0.5降低到0.3
- 增加生物标志物权重1.5倍
- 增强集成学习权重

**预期效果**：
- 敏感性提高20-30%
- 特异性可能略微下降（5-10%）

### 策略2：提高阈值（特异性低）

**适用情况**：特异性 < 0.5，敏感性正常

**操作**：
- 将预测阈值从0.5提高到0.7
- 减少生物标志物权重到0.8倍
- 采用更保守的预测

**预期效果**：
- 特异性提高20-30%
- 敏感性可能略微下降（5-10%）

### 策略3：综合改进（两者都低）

**适用情况**：敏感性和特异性都 < 0.5

**操作**：
- 使用中等阈值（0.5）
- 显著增加集成学习权重（1.5倍）
- 扩大时间序列上下文窗口（10个样本）
- 增加生物标志物权重（1.2倍）

**预期效果**：
- 敏感性和特异性都提高15-25%

### 策略4：生物标志物增强

**适用情况**：生物标志物预测准确率高（>0.7）

**操作**：
- 降低阈值0.15
- 增加生物标志物权重

**预期效果**：
- 在保持特异性的同时提高敏感性

## 生物标志物利用方法

### 方法1：直接匹配增强

**原理**：
- 在样本中查找匹配的生物标志物
- 如果找到，增加Preictal预测概率

**实现**：
```python
matches = biomarker_matcher.find_matching_biomarkers(sample_data)
if matches:
    # 增强Preictal概率
    enhanced_probs[1] += boost_strength
```

### 方法2：频率统计调整

**原理**：
- 统计生物标志物在不同类别中的出现频率
- 如果生物标志物在Preictal中更常见，降低阈值

**实现**：
```python
# 统计生物标志物出现情况
if biomarker_present:
    if true_label == 1:
        stats['biomarker_present_and_preictal'] += 1
    else:
        stats['biomarker_present_and_interictal'] += 1

# 计算准确率
preictal_rate = stats['biomarker_present_and_preictal'] / stats['biomarker_present']
if preictal_rate > 0.7:
    threshold -= 0.15  # 降低阈值
```

### 方法3：多生物标志物集成

**原理**：
- 同时考虑多个生物标志物
- 如果多个标志物都出现，增强效果更强

**实现**：
```python
matches = biomarker_matcher.find_matching_biomarkers(sample_data)
n_matches = len(matches)
if n_matches > 1:
    boost_strength *= min(1.5, 1.0 + 0.1 * n_matches)  # 最多1.5倍
```

### 方法4：通道特异性

**原理**：
- 某些生物标志物只在特定通道出现
- 根据通道信息调整权重

**实现**：
```python
# 检查生物标志物的通道
biomarker_channels = biomarker['channels']
if set(biomarker_channels).intersection(set(important_channels)):
    # 重要通道的生物标志物，权重更高
    boost_strength *= 1.2
```

## 性能优化建议

### 1. 参数调优

**生物标志物权重**：
- 初始值：0.3
- 调整范围：0.2-0.4
- 如果假阳性多，降低权重
- 如果漏检多，增加权重

**阈值调整步长**：
- 初始值：0.05
- 调整范围：0.02-0.1
- 如果性能波动大，减小步长
- 如果收敛慢，增大步长

### 2. 数据质量

**生物标志物质量**：
- 确保生物标志物文件完整
- 检查生物标志物的时间范围是否正确
- 验证通道信息是否准确

**样本质量**：
- 确保EEG数据预处理正确
- 检查数据格式是否一致
- 验证标签是否正确

### 3. 计算效率

**优化建议**：
- 缓存生物标志物匹配结果
- 限制时间序列上下文长度（最多100个）
- 批量处理预测（如果可能）

### 4. 监控和调试

**监控指标**：
- 实时跟踪敏感性和特异性
- 记录阈值调整历史
- 统计生物标志物匹配率

**调试工具**：
- 使用 `get_statistics()` 查看统计信息
- 使用 `get_patient_statistics()` 查看患者特定信息
- 保存配置以便复现结果

## 常见问题

### Q1: 生物标志物目录不存在怎么办？

**A**: 后处理流程会跳过生物标志物增强，但其他功能（动态阈值、低性能处理）仍然可用。

### Q2: 如何确定最佳参数？

**A**: 建议使用交叉验证或留一法来调优参数。从默认值开始，逐步调整。

### Q3: 低性能患者策略何时生效？

**A**: 需要在 `evaluate_and_update()` 中注册患者性能后，策略才会生效。

### Q4: 如何保存和加载配置？

**A**: 使用 `DynamicThresholdAdjuster` 的 `save_config()` 和 `load_config()` 方法。
